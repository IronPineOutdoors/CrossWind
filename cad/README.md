# CAD

Store CAD exports and source files here once the physical prototype dimensions settle.

Keep exported PDFs or STEP files alongside native CAD files so collaborators can view designs without the original CAD tool.

Alpha controller-lid CAD must account for the verified 2.42-inch SSD1309 OLED and its official five-conductor, five-position JST harness. See `phase-1/README.md` and `../electrical/oled-lid-harness.md`; use measurements from installed hardware rather than generic display or JST dimensions.
