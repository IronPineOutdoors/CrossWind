# Wide Base Foot

Print four copies of `crosswind_alpha_base_foot.stl` for the wooden base.

- 50 x 50 mm footprint
- 20 mm lift
- Rounded 6 mm corners
- 6.5 mm bolt-through hole for an M6 or 1/4-inch-class fastener
- 20 mm top recess for a washer and bolt head
- 40 x 40 x 2 mm underside recess for a rubber or neoprene pad

Use PETG, ASA, or another outdoor-capable material with generous walls and infill. The printed feet are spacers and impact pads, not substitutes for properly sized structural fasteners. Confirm bolt length against the actual 3/4-inch wooden member before assembly.

## Regeneration

```powershell
python .\generate_stl.py
```

Requires `manifold3d`.
